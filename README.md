## What I Work On

### Measurement Implementation
Designing event architectures, tracking plans, dataLayer specifications, ecommerce measurement, and conversion tracking across web and mobile applications.

### Attribution
Implementing and troubleshooting mobile attribution, campaign measurement, deep linking, SKAdNetwork, MMP integrations, and advertising platform signals.

### Server-Side Measurement
Working with Server-Side GTM, Conversion APIs, backend events, CRM data, offline conversions, and first-party measurement infrastructure.

### Analytics QA
Investigating missing events, duplicates, incorrect parameters, attribution discrepancies, broken tracking logic, and inconsistent data across platforms.

### Data & Reporting
Using BigQuery, SQL, Python, GA4, Looker Studio, and other analytics tools to validate data and translate measurement into actionable insights.
